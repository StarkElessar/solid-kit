# Маска ввода пикеров. План реализации

> **Для исполнителя:** REQUIRED SUB-SKILL: superpowers:executing-plans. Шаги с чекбоксами. Каждая часть заканчивается зелёной `pnpm check` (код возврата проверять отдельно) и своим коммитом.

**Цель:** фильтр символов и автоформат при вводе в DatePicker, TimePicker, DateTimePicker (спека `docs/superpowers/specs/2026-11-03-stage-5-picker-mask-design.md`).

**Архитектура:** чистый движок `maskText` по описанию частей (`MaskSpec`), описания для даты, времени и даты со временем из локали, применение в `PickerField` через проп `mask`; поле остаётся обычным `<input>`.

**Глобальные ограничения:** как в плане DateTimePicker; не пушить и не ставить теги без слова владельца.

- [x] `date-mask-spec`, `time-mask-spec`, `date-time-mask-spec` (+ тесты для `ru`, `en-US`, `ja`, `hour12`, `ko`).
