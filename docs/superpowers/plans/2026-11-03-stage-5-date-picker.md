# DatePicker и PickerField. План реализации

> **Для исполнителя:** REQUIRED SUB-SKILL: superpowers:executing-plans. Шаги с чекбоксами. Каждая часть заканчивается зелёной `pnpm check` и своим коммитом.

**Цель:** DatePicker на общей оболочке `PickerField` (спека `docs/superpowers/specs/2026-11-03-stage-5-date-picker-design.md`, далее «спека»).

**Архитектура:** `selectOnToday` в Calendar (по умолчанию `true`, решение владельца 2026-11-03); текстовые хелперы дат по локали; `PickerField` (поле, значок, панель, правила открытия) без знаний о датах; DatePicker собирает их и Calendar.

**Стек:** Solid 1.9, CSS Modules с нативной вложенностью, Vitest + `@solidjs/testing-library`, `FloatingPanel` и `createControllableSignal` из кита.

## Решения владельца (все рекомендации раздела 12 спеки приняты)

1. Клик по значку при открытой панели закрывает её. 2. Год только из 4 цифр. 3. Текст принимается по Enter и уходу из поля, календарь показывает набранное сразу. 4. `selectOnToday` по умолчанию `true` (отличается от спеки: там было `false`). 5. Значок вне порядка Tab.

## Глобальные ограничения

Как в плане Calendar: один компонент, тип или функция на файл; нативная вложенность CSS, токены, без литералов цветов; пропсы не деструктурируются; не пушить и не ставить теги без слова владельца; коммит после проверки кода возврата `pnpm check`.

## Часть 1: Calendar `selectOnToday`

- [x] Проп `selectOnToday?: boolean` (по умолчанию `true`): «Сегодня» выбирает дату (`onValueChange`, фокус на ячейке), при `false` только переносит показ. Режим дней возвращается в обоих случаях.
- [x] Тесты: выбор по умолчанию, `selectOnToday={false}` не выбирает, кнопка отключена вне диапазона; поправить старые тесты и спеку Calendar (раздел 2, 3, 10 вопрос 1), текст страницы playground.
- [x] Коммит `feat(calendar): «Сегодня» выбирает дату, проп selectOnToday`.

## Часть 2: хелперы текста даты (`src/utils/date/`)

- [x] `datePattern(locale)`, `formatDateText(parts, locale)`, `parseDateText(text, locale)` и тесты для `ru`, `en-US`, `de`, `ja` (порядок, разделитель, ведущие нули, разбор с любыми разделителями и слитно, год ровно из 4 цифр, несуществующие даты, пустая строка, запасной образец при сбое `Intl`).
- [x] Коммит `feat(date): текст даты по локали`.
