# Этап 4а, часть 4: контекстное меню строки, хост панелей, правило прокрутки, состояния. План реализации

> **Для исполнителя:** шаги отмечены чекбоксами (`- [ ]`). Задачи выполняются по порядку; в задачах с кодом сначала красный тест, потом реализация, потом `pnpm check` (код возврата проверяется отдельной командой) и коммит. Раскладка, top layer, настоящие клавиши и прокрутка в jsdom не проверяются: их проверяют задачи 5–6 в Chrome.

**Цель:** всё, что связано со слоями, фокусом и доступностью состояний: контекстное меню строки (`rowContextMenu`, мышь и клавиатура), хост панелей (панель из ячейки монтируется в корень грида), правило прокрутки (меню закрывается, панель ячейки живёт, пока жива строка; фокус не теряется на `body`), состояния загрузки и пусто, объявление результата.

**Архитектура:** меню строки это один `ContextMenu.Root` грида с внешней точкой (`anchorPoint`, у корня появляются `anchorSource` и `anchorArea`), открывается делегированными `contextmenu` и `keydown` на `<tbody>`; строка меню запоминается в момент открытия. Хост панелей это `PanelHostContext` на корне. Потеря фокуса при размонтировании строки закрывается одной функцией `rescueFocus`, которая вызывается из очистки `GridRow`. Состояния это три ветки внутри `GridBody` (`Switch`), полоса прогресса и скрытая live-область отдельными компонентами.

**Стек:** Solid 1.9, CSS Modules, vitest 5 (jsdom), `ContextMenu`, `Select`, `Button`, `Checkbox` кита, Chrome для слоёв, фокуса и прокрутки.

**Спек:** `docs/superpowers/specs/2026-10-31-stage-4a-grid-core-design.md` (разделы 8, 9, 10, 13 критерии 5, 6, 8); части 1–3: `…-stage-4a-pure-functions.md`, `…-stage-4a-table.md`, `…-stage-4a-sort-and-selection.md`.

## Состав части и решения

В `GridProps` добавляются: `rowContextMenu`, `loading`, `loadingLabel` (`'Загрузка'`), `emptyText` (`'Ничего не найдено'`), `emptyHint`, `onEmptyReset`, `emptyResetLabel` (`'Сбросить фильтры'`), `foundText` (`(count: number) => string`).

1. **Меню строки.** Один `ContextMenu.Root` на грид, рисуется только если передан `rowContextMenu` (иначе `contextmenu` не перехватывается и браузерное меню остаётся). Открытие мышью: `contextmenu` на `<tbody>`, строка = ближайший `tr[data-index]` (интерактивность цели не проверяется: правый клик по чекбоксу тоже открывает меню), `preventDefault`, точка = `clientX/clientY`, источник `'pointer'`. С клавиатуры: `keydown` на `<tbody>`, клавиша `ContextMenu` или `Shift+F10`, на любом элементе внутри строки; точка = нижний левый угол цели (`elementPoint`), источник `'keyboard'` (фокус уходит на первый пункт). Шапка и spacer-строки меню не открывают. Правый клик строку не выбирает. Содержимое `rowContextMenu(row)` вызывается лениво при открытии.
2. **Расхождение со спеком, закладывается заранее:** спек хранит для открытого меню ключ строки; здесь запоминается сама строка в момент открытия (индекс берётся из `data-index` события, строка из `rows`). Смещение окна рендера на открытое меню не влияет, замена `rows` при открытом меню его не перестраивает; закрытие остаётся за Esc, кликом вне, выбором пункта, прокруткой и изменением размера окна (всё это уже умеет `ContextMenu.Content`).
3. **Расширение `ContextMenu.Root`** (общий код, не только грид): `anchorSource?: MenuOpenSource` (по умолчанию источник открытия берётся из `openAt`, внешняя точка может задать его сама) и `anchorArea?: HTMLElement | undefined` (область вызова без `ContextMenu.Trigger`: от неё считается запасной получатель фокуса). `ContextMenu.Content` возвращает фокус тому, кто держал его до открытия, но если этот элемент уже вышел из документа (строка вышла из окна рендера), фокус идёт на область вызова. Грид передаёт корень как `anchorArea`.
4. **Хост панелей.** Корень даёт `PanelHostContext` (`() => rootElement`). Панели из ячеек (Select, Combobox, Popover) и меню строки монтируются в корень, а не в `<table>`. Событийная изоляция панели уже есть (клики и двойные клики внутри панели не доходят до обработчиков строки), в этой части она только проверяется тестами и в Chrome.
5. **Правило прокрутки.** Меню закрывается прокруткой (есть). Панель ячейки остаётся открытой, пока её строка смонтирована; когда строка выходит из окна рендера, панель закрывается очисткой компонента без ошибок, а фокус, если он был внутри строки (или вернулся на её элемент из панели), переходит на корень грида (`tabindex="-1"` есть). Реализация: `rescueFocus(container, fallback)` вызывается из `onCleanup` в `GridRow`; очистка выполняется до удаления DOM, поэтому `container.contains(document.activeElement)` ещё верно; перенос фокуса откладывается в микрозадачу и делается только если после удаления активен `body`. Те же очистки покрывают переход в загрузку и в пусто (строки заменяются).
6. **Загрузка.** Рамка и шапка на месте, `<tbody>` заменён заглушками строк (число = `clientHeight` скроллера / высота строки, не меньше 5 и не больше 20; по одной ячейке-заглушке на колонку, без sticky; `aria-hidden`; пульсация прозрачности); под шапкой полоса прогресса `role="progressbar"` с `aria-label={loadingLabel}` (без `aria-valuenow`); корень получает `aria-busy="true"`; главный чекбокс отключён, ручки ресайза не реагируют; сортировка остаётся включённой. Прокрутка после загрузки начинается сверху (скроллер ограничивает `scrollTop` по короткому телу): принято.
7. **Пусто.** `rows.length === 0` и нет загрузки: `<tbody>` заменён одной строкой с блоком по центру видимой области (`emptyText`, `emptyHint`, кнопка `emptyResetLabel` только если передан `onEmptyReset`); шапка остаётся. Блок остаётся в видимой области при горизонтальной прокрутке: sticky с `inline-size` из переменной `--s-kit-grid-view-w` (ширина скроллера, пишется на корень `ResizeObserver`-ом скроллера).
8. **Объявление результата.** Скрытая область `aria-live="polite"` стоит соседом корня (фрагмент `<>корень + область</>`), потому что корень получает `aria-busy`. После окончания загрузки (`loading` стало `false`) произносит `foundText(rows.length)` или `emptyText` при пустом результате; при начале загрузки очищается; в первый рендер и без смены `loading` ничего не объявляется. По умолчанию `foundText` склоняет через `Intl.PluralRules('ru')`: «Найдена 1 запись», «Найдено 3 записи», «Найдено 5 записей».
9. Анимации (пульсация, полоса) отключаются при `prefers-reduced-motion: reduce`.
