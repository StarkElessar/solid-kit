# Этап 5, часть 3. TimePicker

Статус: принята владельцем 2026-11-03 (вопросы 1–5 раздела 12 подтверждены словом «да», 6–10 приняты по рекомендациям), реализация по плану `docs/superpowers/plans/2026-11-03-stage-5-time-picker.md`. Зонтичный спек: `2026-10-28-solid-kit-umbrella-design.md` (далее «зонтичный»), спека DatePicker и `PickerField`: `2026-11-03-stage-5-date-picker-design.md` (далее «спека DatePicker»). Здесь только то, чего в них нет: поле времени, панель выбора времени, хелперы времени. Поле, значок, правила открытия и фокуса, форма и `Field` приходят от `PickerField` без изменений. DateTimePicker получит свою спеку после TimePicker и встроит панель времени из этой спеки.

## 1. Рамки

**TimePicker** это поле времени суток: текстовый ввод, значок часов и панель с колонками часов и минут в плавающей панели. Значение это ISO-строка `'14:30'` (`HH:mm`, 24 часа) или `null` (раздел 2 зонтичного). Часового пояса, секунд и даты у значения нет: это «время на стенных часах», поэтому переходы на летнее время его не касаются.

**Правила открытия те же, что у DatePicker (требование владельца 2026-11-03):** клик по полю открывает панель, клик по значку открывает (при открытой закрывает), ArrowDown открывает и переносит фокус в панель. Они живут в `PickerField` и здесь не переопределяются.

**Вне объёма (первая версия):** секунды и миллисекунды; диапазон времени (`TimeRangePicker`); циферблат со стрелками; маска ввода; пользовательский формат (`format`, `parse`); интервалы через полночь (`min` позже `max`); часовые пояса; ввод длительностей (больше 23:59).

## 2. Что меняется в существующем

- **`PickerField`:** не меняется. Если при реализации понадобится правка (например, ширина панели), она описывается в итогах и коммите.
- **Новое:** `src/utils/time/` (хелперы, раздел 4), `src/components/time-picker/` (компонент и панель колонок, разделы 5 и 6), подпуть `@stark/solid-kit/time-picker` (по тому же правилу, что у DatePicker; проверяет `verify-package-form.sh`).
- **Панель колонок `TimeColumns`** это внутренний компонент (не публичный API) в `src/components/time-picker/`: DateTimePicker встроит его рядом с Calendar. Поэтому он не знает про поле и принимает значение и колбэки пропсами.
- ListBox не используется: в колонке не больше 60 строк, нет поиска и виртуализации, а три колонки с общей клавиатурной моделью проще собрать из кнопок. Общего с ListBox только модель `role="listbox"`/`option`.

## 3. Публичный API TimePicker

```ts
value?: string | null;                 // 'HH:mm', 24 часа
defaultValue?: string | null;
onValueChange?: (value: string | null) => void;

open?: boolean;
defaultOpen?: boolean;
onOpenChange?: (open: boolean) => void;

min?: string;                          // 'HH:mm', включительно
max?: string;
isTimeDisabled?: (time: string) => boolean;   // получает 'HH:mm'
minuteStep?: 1 | 2 | 5 | 10 | 15 | 20 | 30;   // шаг колонки минут, по умолчанию 1

locale?: string;                       // по умолчанию 'ru'; формат текста и подписи
hour12?: boolean;                      // 12-часовой вид текста и панели; по умолчанию как у локали
showNow?: boolean;                     // кнопка «Сейчас» в подвале панели, по умолчанию true
placeholder?: string;
disabled?: boolean;
readOnly?: boolean;
clearable?: boolean;                   // по умолчанию false
name?: string;                         // скрытое поле с 'HH:mm' для форм
size?: 'sm' | 'md' | 'lg';
labels?: Partial<TimePickerLabels>;
// остальные атрибуты input (id, aria-*, required, autofocus, onBlur, onFocus…) попадают на <input>
```

- Тройки `value` и `open` через `createControllableSignal` (имя `TimePicker`).
- Значение в `value`, `min`, `max`: строго `HH:mm` (`'09:05'`, не `'9:05'`, не `'09:05:00'`). Недопустимая строка: dev-предупреждение и поведение как у «пусто» (`readTimeProp`, по образцу `readDateProp`). `min` позже `max`: dev-предупреждение, границы игнорируются.
- **Значение, не попадающее в `minuteStep`** (`'14:07'` при шаге 15) допустимо в `value` и тексте: шаг ограничивает только колонку и «Сейчас», не ввод. Выбранной в колонке минут при этом строки нет, подсвечивается ближайшая меньшая по шагу как цель фокуса (вопрос 6).
- `isTimeDisabled` вызывается для проверки конкретного времени (ввод, «Сейчас») и для строк колонок (раздел 6): функция должна быть дешёвой и чистой.
- `TimePickerLabels` (русский по умолчанию, `DEFAULT_TIME_PICKER_LABELS`): `openPicker` («Открыть выбор времени»), `clear` («Очистить»), `panel` (имя диалога, «Выбор времени»), `hours` («Часы»), `minutes` («Минуты»), `period` («AM/PM»), `now` («Сейчас»), `hourPart` («чч»), `minutePart` («мм») для подсказки.

### Текст в поле

- **Формат по локали и `hour12`:** `ru` и `de` `14:30`; `en-US` `2:30 PM`; `ja` `14:30`. Образец (порядок частей, разделитель, цикл часов, названия AM и PM) берётся из `Intl.DateTimeFormat(locale, { hour: '2-digit', minute: '2-digit', hour12 }).formatToParts`; запасной образец `HH:mm` с двоеточием.
- **Разбор набранного** (`parseTimeText`): допускаются цифры подряд и части через любой нецифровой разделитель. Правила:
  - 1–2 цифры: только часы, минуты `00` (`9` → `09:00`, `14` → `14:00`);
  - 3 цифры: `930` → `09:30`; 4 цифры: `1430` → `14:30`;
  - с разделителем: часы 1–2 цифры, минуты ровно 2 цифры (`9:30`, `9.30`, `9 30`); `9:5` не принимается (вопрос 4);
  - 12-часовой вид: суффикс `AM`/`PM` любого регистра, с точками и без (`2:30pm`, `2:30 p.m.`) плюс названия периода локали из образца. Без суффикса час 1–11 считается до полудня (`2:30` это `02:30`, вопрос 5), `12` это полдень (`12:30` остаётся `12:30`), а `0` и `13`–`23` принимаются как 24-часовая запись (`14:30` остаётся `14:30`); в 24-часовом виде суффикс не принимается (`null`);
  - диапазон: часы 0–23; с суффиксом только 1–12 (`12 AM` это `00`, `12 PM` это `12`), минуты 0–59, иначе `null`;
  - пустая строка даёт `null`.
- **Принятие и откат как у DatePicker:** текст хранится отдельно от значения; принимается по Enter и при уходе из поля; пустой текст принимается как `null`; невалидный или запрещённый (`min`, `max`, `isTimeDisabled`) откатывается к тексту значения. Набранное допустимое время сразу подсвечивается и прокручивается в колонках открытой панели, значение при этом не меняется.
- Внешнее изменение `value` обновляет текст, если пользователь не печатает. `Esc` при открытой панели закрывает её, при закрытой откатывает набранное.

## 5. Панель (`TimeColumns`)

**Раскладка.** Две колонки (часы, минуты) или три в 12-часовом виде (часы 12, 1…11, минуты, период AM и PM). Под колонками необязательный подвал с кнопкой «Сейчас». Колонка это прокручиваемый `role="listbox"` фиксированной высоты (по умолчанию 8 строк, `--s-kit-time-picker-rows`), строки это `<button role="option">` высотой `--s-kit-time-picker-row`. Выбранная строка заливается акцентом, как выбранный день Calendar. Колонка не растёт и не меняет высоту панели при смене значения.

**Модель выбора (одно значение, всегда целое время).** Панель редактирует то же значение, что поле; каждый выбор сразу вызывает `onValueChange`:

| Действие | Результат |
|---|---|
| Выбор часа | значение = выбранный час + текущие минуты (если значения нет, минуты `00`); в 12-часовом виде период сохраняется (если значения нет, `AM`); панель остаётся открытой, при клавиатуре фокус уходит в колонку минут |
| Выбор минут | значение = текущий час (если значения нет, `00`) + выбранные минуты; если колонка последняя (24 часа), панель закрывается, фокус возвращается в поле |
| Выбор AM/PM (12-часовой) | пересчитывает час на ±12 при сохранении 12-часовой цифры; последняя колонка, панель закрывается |
| «Сейчас» | значение = локальное время, округлённое вниз по `minuteStep`; закрывает панель и возвращает фокус в поле; отключена, если полученное время не допускается |
| Повторный выбор того же значения | панель всё равно закрывается (если колонка последняя), как у DatePicker |

**Подтягивание минут.** Если выбранный час с текущими минутами недопустим (например, `min` 09:30, значение 08:15, выбран час 09), минуты берутся первой допустимой строкой колонки в этом часе (09:30). То же при выборе периода в 12-часовом виде. Час, в котором нет ни одной допустимой минуты, и период, для которого нет допустимого времени, отключены.

**Что допустимо.** Строка колонки часов отключена, если во всём часе нет ни одной допустимой минуты по `minuteStep` (проверка `isTimeAllowed`). Строка минут отключена, если время «текущий час : эта минута» не допускается; если часа ещё нет, смотрится час, который выбрал бы выбор минут (`00`). Отключённая строка имеет `aria-disabled`, не выбирается кликом и Enter, но остаётся в порядке стрелок (как у Calendar) и пропускается при перемещении, как отключённые дни.

**Клавиатура.** Колонки это три остановки Tab (внутри колонки roving tabindex, одна строка с `tabindex="0"`, цель фокуса `data-focus-target` у первой колонки):

| Клавиша | Действие |
|---|---|
| ArrowUp, ArrowDown | предыдущая или следующая допустимая строка колонки (без перехода по кругу) |
| Home, End | первая или последняя допустимая строка |
| PageUp, PageDown | на 6 строк для часов, на 6 строк для минут (вопрос 7), с зажатием по краям |
| ArrowLeft, ArrowRight | соседняя колонка, фокус на выбранной или ближайшей допустимой строке |
| Enter, Space | выбор строки по правилам таблицы выше (`preventDefault`: форма не отправляется) |
| Tab, Shift+Tab | следующая или предыдущая колонка, затем «Сейчас»; из последней остановки Tab закрывает панель и возвращает фокус в поле (`PickerField` с `panelTab='move'`; до 2026-11-03 оболочка закрывала панель на любой Tab, исправлено при работе над DateTimePicker) |
| Esc | закрывает панель, фокус в поле (стек слоёв) |

Стрелки только двигают фокус, значение не меняется до Enter, Space или клика (вопрос 3).

**Прокрутка.** При открытии и при смене набранного текста колонки сами прокручиваются так, чтобы выбранная (или цель фокуса, если значения нет) строка была по центру видимой области: `scrollTop` самой колонки, без `scrollIntoView` (чтобы не прокручивать страницу). Без анимации.

**Цель фокуса при пустом значении:** текущий час и минута, округлённая вниз по шагу (выбранной строки нет, она только получает фокус и рамку).

## 6. Вид

Оболочка поля это `PickerField` (высота `--s-kit-control-height`, кольцо фокуса на оболочке, значок справа). Значок часов 16 px цвета `--s-kit-color-muted`. Ширина по умолчанию `--s-kit-time-picker-width` (7rem: помещается `14:30`; для 12-часового вида 8.5rem, помещается `12:30 PM`; `clearable` добавляет квадрат кнопки очистки, как у DatePicker). Панель: общий материал панелей, колонки с разделителями в токен границы, высота колонки 8 строк, ширина колонки по содержимому с минимумом. Токены: существующие плюс `--s-kit-time-picker-width`, `--s-kit-time-picker-row` (высота строки, по умолчанию как у ячейки Calendar), `--s-kit-time-picker-rows` (видимых строк, 8). Фокус строки: кольцо `data-s-kit-focus-inset`, на залитой выбранной строке контрастное кольцо (`--s-kit-focus-ring-on-fill`), как у Calendar. CSS с нативной вложенностью, без литералов цветов, имена классов в kebab-case.

## 7. Доступность

- Поле: `aria-haspopup="dialog"`, `aria-expanded`, `aria-controls`; `aria-invalid` и `aria-describedby` от `Field` (всё это даёт `PickerField`).
- Панель: `role="dialog"`, `aria-label` из `labels.panel`; внутри колонки `role="listbox"` с `aria-label` (`hours`, `minutes`, `period`) и `aria-orientation="vertical"`, строки `role="option"`, `aria-selected`, `aria-disabled` у запрещённых.
- Значок и «Очистить» имеют `aria-label`, вне порядка Tab (как у DatePicker).
- «Сейчас» это обычная кнопка с текстом.
- Цвет не единственный признак выбора: у выбранной строки `aria-selected` и заливка с контрастом не ниже 4.5:1 (проверяется автопроверкой в обеих темах).
- Esc закрывает сначала панель, потом внешний диалог (раздел 8.3 зонтичного).

## 10. Критерии готовности

- а) клик по полю открывает панель, второй клик её не закрывает; клик по значку открывает, повторный закрывает; значение до выбора не меняется;
- б) открытие кликом оставляет курсор в поле; ArrowDown и Alt+ArrowDown переносят фокус в колонку часов;
- в) выбор часа и минут обновляет значение и текст; выбор минут закрывает панель (24 часа), выбор периода закрывает панель (12 часов); фокус возвращается в поле;
- г) набранное время подсвечивается в колонках до принятия; Enter и уход из поля принимают; `9`, `930`, `14:30`, `9.30` разбираются; `9:5`, `25:00`, `12:60` откатываются; пустое значение даёт `null`;
- д) `min`, `max`, `isTimeDisabled`, `minuteStep`, `disabled`, `readOnly`, `clearable`, `name` (значение в `FormData`), «Сейчас» работают; недопустимые строки не выбираются и пропускаются стрелками;
- е) 12-часовой вид (`en-US` или `hour12`): три колонки, `12 AM` это `00:00`, `12 PM` это `12:00`, значение остаётся 24-часовым ISO;
- ж) внутри `Field` поле получает `id`, `aria-describedby`, `aria-invalid`; подпись фокусирует поле и не открывает панель;
- з) панель не обрезается предками с `overflow`, `transform`, `filter`, `contain`; в диалоге Esc закрывает сначала панель, потом диалог;
- и) обе темы читаемы, контраст выбранной строки не ниже 4.5:1; хелперы покрыты тестами для `ru`, `en-US`, `de`, `ja`; `pnpm check` и `verify-package-form.sh` зелёные;
- к) TimePicker стоит в ряду контролов той же высоты на странице темы, критерий 7 зонтичного для него пройден.

## 11. Применённые паттерны и границы абстракций

- **Композиция вместо наследования:** TimePicker это `PickerField` плюс `TimeColumns`; от DatePicker отличается только текстом и содержимым панели.
- **Adapter:** ISO-строка `HH:mm` ↔ `TimeParts` ↔ текст по локали, преобразование один раз на границе компонента.
- **Strategy:** формат и разбор текста через `timePattern(locale, hour12)`.
- **Чистая модель отдельно от разметки:** допустимость строк, цель фокуса и соседние строки считает `time-columns-state.ts` без DOM, разметка только рисует.
- TimePicker зависит от `PickerField`, хелперов времени и `TimeColumns`; DatePicker и Calendar от него не зависят. DateTimePicker позже зависит от `TimeColumns` и Calendar.

## 12. Открытые вопросы (рекомендации)

1. **Закрытие панели.** Рекомендация: панель закрывается выбором в последней колонке (минуты или период), «Сейчас» тоже закрывает; поправить час после минут можно повторным открытием. Альтернатива: панель остаётся открытой до клика снаружи или Esc (удобнее править, но ни один выбор не «завершает» ввод).
2. **Выбор с пустым значением.** Рекомендация: недостающая часть берётся как `00` (час или минуты), значение появляется сразу после первого выбора. Альтернатива: значение появляется только после выбора обеих частей (промежуточное состояние «час выбран, минут нет» усложняет модель и форму).
3. **Стрелки двигают только фокус.** Значение меняется по Enter, Space или клику (как в Calendar). Альтернатива: выбор следует за фокусом (быстрее, но каждый шаг стрелкой вызывает `onValueChange`).
4. **Минуты при вводе с разделителем ровно из 2 цифр** (`9:5` не принимается), по той же причине, что год из 4 цифр в DatePicker: нет двусмысленности. Альтернатива: `9:5` это `09:05`.
5. **12-часовой ввод без AM или PM.** Рекомендация: принимается, час считается по 12-часовой шкале до полудня (`2:30` это `02:30`), период можно поправить в панели. Альтернатива: требовать суффикс.
6. **Значение вне шага** (`14:07` при `minuteStep` 15) допустимо в тексте и `value`; в колонке подсвечивается ближайшая меньшая по шагу как цель фокуса, выбранной строки нет. Альтернатива: округлять при принятии (теряет введённое).
7. **PageUp и PageDown** сдвигают на 6 строк и в часах, и в минутах (для минут при шаге 1 это 6 минут). Альтернатива: часы на 6, минуты на 15 (скачки четвертями).
8. **Секунды в первой версии нет.** Значение `HH:mm` фиксировано зонтичным. Секунды понадобятся для «времени события», тогда отдельным шагом (`HH:mm:ss`, колонка секунд).
9. **«Сейчас» включён по умолчанию** (`showNow`), по аналогии с «Сегодня» в Calendar. Альтернатива: выключен.
10. **Колонки вместо списка времён с шагом** (как в Google Calendar: единый список `09:00, 09:15…`). Рекомендация: колонки, потому что подходят и для минутного шага, и для 12 часов; список с шагом хорош только для выбора из 4–96 слотов и может стать отдельным режимом позже.

## 13. Что не проверено

Всё, что касается браузеров, кроме Chrome; сенсорные устройства (колонки с инерционной прокруткой, экранная клавиатура поднимается при открытии кликом по полю); IME при вводе времени; автозаполнение браузера (`autocomplete="off"`); экранные читалки (как читаются колонки `listbox` внутри `dialog`); локали с нелатинскими цифрами и периодами (`ar`, `hi`) и порядком «период перед временем» (`ko`, `ja` в 12-часовом виде): разбор и формат для них проверяются таблицей, но не глазами.

## 14. Итоги реализации и приёмки (2026-11-03)

Страница playground «Выбор времени» (`playground/src/time-picker-page.tsx`, демо в `demo-time-pickers.tsx`, проверки в `time-picker-checks.ts`).

**Автопроверки в Chrome: 40 из 40** в системной, светлой и тёмной темах, повторные прогоны идемпотентны. Покрыто: критерии а–е, з, и (контраст выбранной строки не ниже 4.5:1) и клик по подписи `Field` (ж); ширина текста в `clearable` и в 12-часовом виде; ограничения, шаг минут, форма, предки с `transform`, `filter`, `contain`, `overflow`.

**Вручную настоящими событиями мыши и клавиш:** клик по полю открывает панель, выбранные строки обеих колонок по центру; клик по часу меняет значение и оставляет панель открытой, фокус остаётся в поле; клик по минутам закрывает панель, фокус в поле; ArrowDown открывает панель и ставит фокус на час; стрелки двигают фокус по колонке и между колонками, значение не меняют; Enter на минутах выбирает и закрывает; набранное `0905` прокручивает колонки к 09 и 05 с подсветкой, Enter принимает; в диалоге панель рисуется поверх него, первый Esc закрывает только панель, второй закрывает диалог (счётчик закрытий 1), фокус возвращается на кнопку; 12-часовой вид показывает три колонки; клик по подписи `Field` фокусирует поле и не открывает панель, клик по самому полю открывает.

**Найдено при приёмке (общий дефект `PickerField`, исправлен):** клик по подписи в `Field` открывал панель, потому что браузер пересылает полю синтетический клик, а оболочка принимала его за клик по полю. Критерий «подпись фокусирует поле и не открывает календарь» стоял и в спеке DatePicker (е), но проверялась только связка `id` и подписи. Теперь оболочка помечает клик по подписи своего поля (`input.labels`) и не открывает панель на пересланный клик; тесты в `picker-field.test.tsx` (подпись через `for`, подпись-обёртка, открытая панель, следующая задача) и автопроверка в обеих страницах (DatePicker 29, TimePicker 40). Исправление относится и к DatePicker.

**Отклонения от спеки:** правило подтягивания минут (раздел 5, добавлено при реализации); без суффикса в 12-часовом виде `12` это полдень, а `0` и `13`–`23` читаются как 24-часовые (раздел 3, уточнено).

**Не проверено:** Firefox, Safari, сенсорные устройства (колонки с инерционной прокруткой), IME, экранные читалки (как читаются `listbox` внутри `dialog`), нелатинские цифры и периоды (раздел 13).
