# Высота грида: фиксированная, `fill`, по содержимому

Статус: реализовано и принято 2026-11-02 по просьбе владельца: грид должен легко растягиваться на всю доступную высоту, а без фиксированной высоты и без `fill` и без данных схлопываться.

## 1. Режимы

| Режим | Как включается | Поведение |
|---|---|---|
| Фиксированный | токен `--s-kit-grid-height` на гриде или предке (например `style`) | ровно эта высота, он же снимает кап; прокрутка внутри |
| Заполнение | проп `fill` | вся доступная высота: во flex-колонке родителя грид растёт (`flex: 1 1 auto`), иначе берёт 100% родителя с определённой высотой; кап снят; футер автосумм у нижнего края; пустое состояние растягивается и стоит по центру свободной области |
| По умолчанию | ничего не задано | высота по содержимому, но не выше `--s-kit-grid-max-height` (32rem), чтобы виртуализация работала; без данных грид схлопывается до шапки и короткого сообщения (минимальной высоты у блока «пусто» нет) |

Прежнее поведение «100% родителя, но не выше 32rem» убрано: заполнение родителя теперь явное (`fill`). Демо грида в playground переведено на `fill`.

## 2. Реализация

- `GridProps.fill`; корень получает `data-fill`; контекст `fill()`.
- Корень: `block-size: var(--s-kit-grid-height, auto)`, `max-block-size: var(--s-kit-grid-height, var(--s-kit-grid-max-height, 32rem))`; `&[data-fill]`: `flex: 1 1 auto; block-size: 100%; max-block-size: none`.
- `fill` без данных: у таблицы `data-stretch` (таблица и строка пустого состояния `block-size: 100%`, ячейка `vertical-align: middle`).
- Глобальный футер у нижнего края при малом числе строк обеспечивает строка-«резинка» (спек автосумм, раздел 3).

## 3. Проверки

Юнит-тесты на `data-fill`, `data-stretch`; автопроверки playground (секция «Высота»): фиксированная высота равна токену, `fill` занимает высоту родителя (с данными и без), футер у нижнего края, пустое состояние по центру, по умолчанию высота по содержимому, без данных грид ниже 150 px. Размеры проверены в Chrome; Firefox и Safari не проверены (процентная высота строк таблицы).
